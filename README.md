# Stopwatch Web App

A lightweight stopwatch built as a static web app. It lets you start/stop timing, record lap times, and reset the timer.

## Tech Stack

- HTML
- CSS
- JavaScript

## Usage

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Use the controls:
   - **Start / Stop** to control the timer
   - **Lap** (while running) to save lap times
   - **Reset** (while stopped) to clear the timer and laps
